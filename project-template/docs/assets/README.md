Shared bibliography and ICES JMS CSL from wise-writing. The CSL retains its embedded CC BY-SA 3.0 attribution. references.bib is the single bibliography of the project: every document links to it, and all references go there, literature and software alike. Add verified primary references by hand; `report_software()` appends the `citation()` entries of the packages a document uses when their keys are missing and never changes existing entries, so hand edits are kept. A citation whose DOI is already in the file, such as the sdmTMB paper, is cited by that entry.
